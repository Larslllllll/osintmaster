# Security policy

Please do not open a public issue for a vulnerability that exposes private data, credentials or users to harm. Contact the repository maintainer privately through GitHub's **Report a vulnerability** feature once the repository is published. Include a minimal reproduction, affected version and impact. Do not include real personal data, API keys or private sessions in a report.

Supported security fixes are planned for the latest minor release. OSINTMaster makes only public requests and never needs account credentials. Treat generated reports as potentially sensitive local files. The tool does not provide a guarantee that third-party websites remain accurate or safe.
