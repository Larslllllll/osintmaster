# Extended site catalogue attribution

`src/osintmaster/data/wmn_catalog.json` adapts selected rules from
**WhatsMyName**, by Micah Hoffman and contributors:

https://github.com/WebBreacher/WhatsMyName/blob/062bcfe48df79fa618e96edc79dc9673f3fe5643/wmn-data.json

The upstream data is licensed under the Creative Commons Attribution-ShareAlike
4.0 International License (CC BY-SA 4.0):

https://creativecommons.org/licenses/by-sa/4.0/legalcode

For this adaptation, OSINTMaster selected GET-only public profile rules,
converted the URL and marker fields to its own registry format, removed
unsupported checks, and added dated positive and negative canary results.
The adapted catalogue data remains CC BY-SA 4.0. OSINTMaster application code
and the original seven-site registry are MIT licensed; see `LICENSE`.
